# Siemens.Internship2026.GradeBook

Small ASP.NET Core 8 Web API refactored for the Siemens internship code review task.

## Endpoints

- `GET /api/grades` - returns all active grades and summary statistics.
- `GET /api/grades/{id}` - returns one active grade by id.

## Run

```bash
dotnet restore
dotnet build
dotnet run
```
